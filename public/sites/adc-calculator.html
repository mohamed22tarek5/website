ADC Resolution & Voltage Calculator

Convert raw ADC digital readings to exact analog pin voltages and pre-divider source potentials. Supports Arduino, ESP32, STM32, PIC, and Raspberry Pi Pico with LSB step sizing.

In a Nutshell

The voltage is calculated by dividing the raw ADC digital reading by the maximum full-scale count (2n − 1) and multiplying by the reference voltage (Vref). For example, on an Arduino Uno (10-bit, 5V), a reading of 512 corresponds to approximately 2.50 V. On an ESP32 (12-bit, 3.3V), a reading of 2048 corresponds to approximately 1.65 V.

Ready-to-Use Code Snippets

Copy calibrated code snippets directly into your firmware project for your selected microcontroller architecture: 

// Arduino Uno / Nano ADC Example
const int ADC_PIN = A0;
const float V_REF = 5.0;            // Reference voltage in Volts
const float DIVIDER_RATIO = 1.0;    // (R1 + R2) / R2 (Set 1.0 if no divider)

void setup() {
  Serial.begin(115200);
}

void loop() {
  int raw = analogRead(ADC_PIN);    // 0 to 1023 (10-bit)
  float vPin = (raw / 1023.0) * V_REF;
  float vSource = vPin * DIVIDER_RATIO;

  Serial.print("Raw: "); Serial.print(raw);
  Serial.print(" | V_pin: "); Serial.print(vPin, 3);
  Serial.print(" V | V_source: "); Serial.print(vSource, 2); Serial.println(" V");
  delay(500);
}

Method of Calculation & Mathematical Formulas

An Analog-to-Digital Converter (ADC) quantizes an analog continuous voltage between 0 V and a known reference voltage (Vref) into a discrete digital integer representation across 2n discrete levels (from 0 to 2n − 1).

1. Quantization Resolution & Step Size (LSB)

The voltage value represented by the Least Significant Bit (LSB) is the theoretical quantization step size:

LSB = Vref ÷ 2n

Note: For an Arduino Uno (n = 10, Vref = 5V): LSB = 5 / 1024 = 4.8828 mV.

2. Voltage From Raw Digital Reading

Because 0 represents 0V and (2n − 1) represents full scale Vref, the voltage at the microcontroller analog pin is:

Vpin = (raw ÷ (2n − 1)) × Vref

3. Converting Target Voltage to Raw Digital Count

Conversely, to determine the expected integer register reading for a known input pin voltage:

raw = round((Vpin ÷ Vref) × (2n − 1))

4. Restoring High Source Voltage via Voltage Divider

When measuring voltages exceeding the microcontroller's Vref (e.g. measuring a 12V battery on a 5V Arduino), an input resistor divider step-down is required:

Vsource = Vpin × ((R1 + R2) ÷ R2) = Vpin × Ratio

Where R1 is connected between Vsource and the ADC pin, and R2 is connected between the ADC pin and Ground.

Practical Worked Engineering Examples

Example 1: Standard Arduino Uno 5V Reading

An analog potentiometer on an Arduino Uno (10-bit, Vref = 5V) yields a raw reading of 512. What is the measured voltage?

V = 512 ÷ 1023 × 5.0V = 2.502 V (≈ 2.50 V) • LSB step = 4.88 mV

Example 2: 12V Car Battery Monitor via Voltage Divider

A 12V automotive battery is measured via a divider with R1 = 30 kΩ and R2 = 10 kΩ on an Arduino Uno (10-bit, 5V). The ADC register returns 600.

1. Pin Voltage: Vpin = (600 / 1023) × 5.0 V = 2.9325 V (≈ 2.93 V)
2. Divider Ratio: (30 + 10) / 10 = 4.0×
3. Battery Voltage: Vbattery = 2.9325 × 4.0 = 11.73 V (≈ 11.7 V)

Example 3: ESP32 12-Bit Sensor Reading

An analog humidity sensor connected to an ESP32 (12-bit, Vref = 3.3V) reports a raw reading of 2048 (half-scale).

V = 2048 ÷ 4095 × 3.3 V = 1.652 V (≈ 1.65 V) • LSB step = 0.806 mV

Frequently Asked Questions

Should I divide by 1023 or 1024 on a 10-bit ADC?
In theoretical DSP theory, an ideal ADC divides the range into 2n (1024) equal quantization bins, with each step equal to Vref / 1024. However, because the maximum integer count returned by the hardware register is 1023 (when Vin = Vref), dividing by 1023 ensures that full-scale reading maps exactly to 100% of Vref. In standard embedded firmware practice, dividing by (2n − 1) is widely accepted for mapping to physical engineering units.
What is the source impedance rule for microcontrollers?
Successive Approximation Register (SAR) ADCs (like those on the ATmega328P and STM32) use an internal sample-and-hold capacitor (typically 14 pF). During sampling, the external signal source must fully charge this capacitor within a few microseconds. The datasheet recommends that the analog source impedance (the Thevenin equivalent resistance R1 || R2) should not exceed 10 kΩ. If using high-value resistors (e.g. 100k / 100k), add a 100 nF ceramic capacitor in parallel with R2 or buffer with an op-amp follower.
How can I improve ADC accuracy on Arduino and ESP32?
To achieve maximum accuracy:
  1. Use a stable reference: On Arduino, switch from noisy USB 5V to the internal 1.1V bandgap (analogReference(INTERNAL)) or an external reference on the AREF pin.
  2. Oversampling & Decimation: Averaging 16 samples can increase effective resolution by 2 bits while reducing Gaussian noise.
  3. Decoupling capacitor: Place a 100 nF ceramic capacitor right next to the AREF pin and the analog input pin.
  4. Discard the first sample: Discard the very first reading after switching analog multiplexer channels.
What is the AREF pin and how do I use it?
The AREF pin allows you to supply an external, highly regulated reference voltage to the ADC. For example, if your sensor only outputs between 0V and 2.5V, applying a precision 2.5V reference to AREF and executing analogReference(EXTERNAL) allows all 1024 digital counts to span 0 to 2.5V, doubling your measurement resolution. Warning: Never apply voltage to AREF without first setting analogReference(EXTERNAL) in code, or you risk shorting the internal reference to your external source!
