# Engineering Tools & Calculators — Mohamed Tarek Abdelhady

Interactive, client-side engineering calculators and developer tools built with vanilla JavaScript for electronics and hardware engineers.

Live suite: https://mohamed-tarek-abdelhady.vercel.app/tools.html

## Available Calculators

1. [Ohm's Law Calculator](/sites/ohms-law-calculator.html) — Calculate Voltage (V), Current (I), Resistance (R), and Power (P).
2. [Resistor Color Code Calculator](/sites/resistor-calculator.html) — 4-band, 5-band, and 6-band resistor color decoding and tolerance calculation.
3. [Resistor for LED Calculator](/sites/resistor-for-led.html) — Calculate exact current-limiting series resistor and power dissipation for single or series LEDs.
4. [Voltage Divider Calculator](/sites/voltage-divider-calculator.html) — Output voltage, resistor values, and loaded voltage divider calculations.
5. [Capacitor Calculator](/sites/capacitor-calculator.html) — Series and parallel capacitance, capacitive reactance (Xc), and RC time constants.
6. [555 Timer Calculator](/sites/555-timer-calculator.html) — Astable frequency, period, and duty cycle; monostable pulse width calculations.
7. [PCB Trace Width Calculator](/sites/pcb-trace-width-calculator.html) — IPC-2221 standard trace width for internal and external conductors given current and temperature rise.
8. [Decibel & dBm Calculator](/sites/decibel-dbm-calculator.html) — Power, voltage, and current dB conversions, dBm to milliwatts and watts.
9. [Op-Amp Gain Calculator](/sites/op-amp-gain-calculator.html) — Inverting, non-inverting, and differential amplifier gain and output voltage calculations.
10. [Battery Life & Solar Calculator](/sites/battery-solar-calculator.html) — Battery runtime estimator, solar panel sizing, and charge controller requirements.
11. [LCD Custom Character Generator](/sites/lcd-custom-character-generator.html) — Visual 5x8 pixel grid editor generating C byte arrays for HD44780 LCD modules.

## Features
- 100% Client-Side: Instant calculation with zero network latency.
- Responsive & Accessible: Works across mobile, desktop, and screen readers.
- Real-time Formulas: Displays mathematical derivation alongside results.
