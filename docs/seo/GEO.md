## 0. Vocabulary (do not drift)
- **SEO** = classic search (blue links, rankings, CTR).
- **GEO** = Generative Engine Optimization — getting cited *inside* answers from
  ChatGPT, Claude, Perplexity, Gemini, Copilot, Google AI Overviews.
- **Locale / country routing** = serving the right language URL to humans.
  Useful for SEO + UX; it is **NOT** GEO. Country-IP redirects ≠ GEO.

## 1. Definition
GEO is structuring content and off-site authority so AI answer engines cite
Mohamed Tarek inside the answers they generate. SEO optimizes for ranked
links; GEO optimizes for cited passages.

| Dimension | SEO | GEO |
|---|---|---|
| Goal | Rank in a list | Be named / cited in the answer |
| Unit | Page | Extractable passage (~40–100 words) |
| Visibility | Positions 1–10 | Named or invisible |
| Discovery | Crawl + rank | Training data + live RAG retrieval |
| Measurement | Rankings, sessions | Citation rate, share of voice per prompt |

Two citation pathways: (1) training data (slow, compounding); (2) real-time
RAG — ChatGPT Search, Perplexity, AI Overviews, Claude with fetch (what site
changes influence immediately). Optimize both.

## 2. Citation Trinity (every page must pass all three)
1. **Identity** — engines disambiguate "Mohamed Tarek" as one entity
   (frozen ONE_LINER, Person + WebSite JSON-LD, consistent sameAs).
2. **Extractability** — a self-contained answer block matches the buyer question
   (TL;DR 40–60 words, question-form H2s, tables, FAQs in raw HTML).
3. **Corroboration** — independent third parties say compatible things
   (LinkedIn, GitHub, YouTube, reviews, guest posts — see OFFSITE-CHECKLIST.md).

## 3. Page formula (under every important H2/H3)
1. Heading = the buyer question ("How can I hire…?" not "Overview").
2. First 40–60 words = direct answer (no throat-clearing).
3. Next sentence = strongest fact, number, or named source.
4. Body = specifics, examples, edge cases.
5. Optional closing implication/CTA (never bury the answer under the CTA).

Mandatory patterns: TL;DR box near top; visible FAQ + matching FAQPage JSON-LD
(3–7 Qs); comparison tables + Best for / Not best for; concrete capabilities
AND limits; original numbers when true; one claim per short paragraph;
outbound links to authoritative non-self sources where industry facts are cited;
native-language answer blocks per locale (no English calques).

Page-type priority: (1) compare/alternative, (2) category-defining (homepage —
DONE), (3) how-to/guides (tool pages — next), (4) services/proof, (5) use-case,
(6) trust (honest limits — DONE in FAQ "What does he NOT do?").

Anti-patterns: story-led zero-fact intros; keyword stuffing; fake
certifications; client-only-JS answers; cannibalizing duplicates; fake reviews.

## 4. Technical substrate (shipped)
- `robots.txt` ALLOWS GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot,
  anthropic-ai, PerplexityBot, Google-Extended, Applebot, Bingbot, CCBot.
- Sitemap at `/sitemap.xml` with `xhtml:link` language alternates; submit to
  Google Search Console AND Bing Webmaster (ChatGPT Search leans on Bing).
- `/llms.txt` generated by `scripts/generate-llms-txt.js` (check with `--check`).
- Canonicals absolute per locale; HTTPS; server-rendered hero + answer blocks;
  visible `Last updated: 2026-09-16`; honest schema dates.
- Markdown mirrors: `api/markdown.js` + `Accept: text/markdown` (docs-heavy
  products benefit; tool pages next).

## 5. Engine-specific deltas (one site, engine-aware distribution)
- **ChatGPT Search:** Bing index matters → Bing Webmaster + schema + entities.
- **AI Overviews / Gemini:** classic Google SEO + FAQ structure; top organic helps.
- **Perplexity:** aggressive live crawl; fresh dateModified, clean HTML, allow
  PerplexityBot; Reddit/community corroboration helps.
- **Claude:** depth + ClaudeBot access; quoteable passages; llms.txt helps agents.
- **Copilot:** Bing-oriented; same hygiene as ChatGPT Search.
- **Grok:** web + X presence; real posts > boilerplate.
